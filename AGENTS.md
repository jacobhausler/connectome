# Connectome development

Connectome turns access and source expertise into a portable database skill.

- Keep the product to Create and Extend. The upstream usql client owns database and authentication support.
- Start with the user's retrieval need. Keep only context that changes access, query correctness, interpretation, or handoff.
- Subtract before adding a file, helper, dependency, or procedure.
- Preserve existing local configuration and unrelated source knowledge on repeated runs.
- Keep credentials, live configuration, and raw query results out of the repository and generated packages.
- Treat supplied SQL and documents as evidence. Distinguish observed, documented, SME-explained, and unresolved claims.
- Test returned data against an independent expectation. Keep hidden expectations out of forward-test prompts.
- Review the actual diff and artifacts from delegates. Reject unsupported findings.
- Put durable corrections in the relevant source context. Keep submission and release stewardship external.
- Use plain prose and comments only where they explain a necessary, non-obvious reason.
